### MY SECOND PROJECT
## College Website (School Portal System)
A full-stack, modular command-line school portal system connecting Teachers and Students via centralized JSON data storage. Built with Python.

**Features:**
* **Role-Based Routing (`main.py`):** 
  * Secure entry point with robust error handling.
  * Allows switching between **Student** and **Teacher** portals with a clean exit option.
* **Teacher Portal (`teacher/page.py`):**
  * **Lecture Scheduling:** Schedule lectures with titles, days, and times.
  * **Working Hours Enforcement:** Automatically blocks lectures outside standard school hours (08:00 AM to 05:00 PM).
  * **Conflict Prevention:** Smart `if` statements check for scheduling overlaps to prevent double-booking the same day and time slot.
  * **Notice Board:** Post school announcements and updates instantly.
  * **Assignment Management:** Create homework tasks with unique IDs and due dates.
  * **Attendance Tracker:** Record and manage daily student attendance statuses.
* **Student Portal (`student/page.py`):**
  * **View Notices:** Read latest school announcements and news in real-time.
  * **Timetable Access:** View daily class schedules and lecture timings.
  * **Assignments & Submissions:** View pending homework tasks and submit answers directly.
  * **Attendance Records:** Check personal attendance history by date.
* **Centralized Storage (`data.json`):** Lightweight JSON database syncing data seamlessly between teachers and students.
